# Skolar - EduTenant

Interfaz web de Skolar, construida con React, TypeScript y Vite.

## Requisitos

- Node.js 22.18 o posterior.
- Backend de EduTenant en ejecución.

## Desarrollo

```bash
npm ci
```

Copia `.env.example` a `.env` y ajusta `VITE_API_URL` si el backend no está disponible en `http://localhost:3000/api`.

```bash
npm run dev
```

## Validación

```bash
npm test
npm run lint
npm run build
```
